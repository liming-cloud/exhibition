## 1. 配色

| 用途 | 类名 | 说明 |
|---|---|---|
| 主色 | `primary-50`～`900` | 按钮、链接、选中态、日期块；常用 600（底色）/ 700（悬停、文字链接）/ 50（浅底） |
| 强调色 | `accent-600` | 只用于「主推」标记等少量醒目处，一屏不超过 2～3 处；实底白字一律用 600 档 |
| 中性色 | `neutral-50`～`900` | 正文 600、标题 900、辅助 500、占位 400、边框 200、浅底 50 |
| 成功 | `emerald-50` / `700` | 「申报中」、提交成功提示 |
| 页脚、顶部联系条 | `neutral-900` | 深色底，图标用 `primary-400` |

主色、强调色是 `assets/css/main.css` 里的 CSS 变量，Tailwind 和 Element Plus 都跟随变化。

**强调色怎么选（2026-11-24 验收意见：原来的互补色对比突兀）**

强调色用主色的**类似色**（色轮上相邻），不用互补色：

| 方案 | 主色（600） | 强调色（600） | 色相差 | 白字对比度 |
|---|---|---|---|---|
| 蓝 | `#066aa3`（H 202°） | 靛蓝 `#4f46e5`（H 243°） | 42° | 6.29 |
| 橙 | `#e74c12`（H 16°） | 玫红 `#e11d48`（H 347°） | 30° | 4.70 |

原来的强调色：琥珀 `#f59e0b`（白字对比度 2.15）、青绿 `#14b8a6`（2.49），和主色色相差 160° 左右，属于互补色，白字对比度也不达标。

依据：
- 类似色和主色的色相差取 30°～60°：小于 30° 看起来像同一个颜色，60° 左右最常用于品牌和界面配色（[ColorArchive](https://colorarchive.org/guides/analogous-color-palette/)、[ColorFYI](https://colorfyi.com/blog/analogous-color-schemes/)）。所以没选只差 10° 的青色 `#0891b2` 和只差 16° 的正红 `#dc2626`
- 类似色之间区分度较低，不能只靠颜色表达含义：「主推」标签一定带文字（[Colormapped](https://colormapped.com/guides/analogous-colors/)）
- 白字标签属于小字，对比度至少 4.5:1（[WCAG 2.1 SC 1.4.3](https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum)），所以实底用 600 档；500 档靛蓝白字只有 4.47，不达标
- 强调色约占 10% 面积，只用于徽标等小元素（[USWDS 60/30/10](https://designsystem.digital.gov/design-tokens/color/theme-tokens/)、[Material 3 tertiary 用于 badge](https://m3.material.io/styles/color/roles)）

## 2. 字体与字号

系统字体（苹方 / 微软雅黑），不加载外部字体。手机 / 桌面：

| 层级 | 类名 | 用在 |
|---|---|---|
| 页面标题 | `text-2xl md:text-4xl font-bold` | `PageBanner`、详情页标题（详情标题完整显示、允许换行） |
| 区块标题 | `.section-title`（24 / 30） | `SectionTitle` |
| 英文小字 | `.section-eyebrow`（12，大写、字距宽） | 标题上方 |
| 卡片 / 行标题 | `text-base font-medium`，最多 2 行（`line-clamp-2`） | `ListRow`、`ContentCard` |
| 正文 | `text-base`（16），行高 relaxed | 富文本正文 |
| 辅助信息 | `text-sm text-neutral-500` | 国家·场馆、日期、摘要 |

## 3. 间距、圆角、阴影、断点

- 内容宽度：`.container`（最大 1280，左右 16 / 24）
- 区块上下间距：`py-12 md:py-16`；区块标题到内容 24（`SectionTitle` 自带 `mb-6`）
- 卡片网格间距：`gap-4 md:gap-6`；列表行间距 `space-y-3`；卡片内边距 16～20
- 圆角：卡片 / 列表行 / 咨询条 `rounded-lg`（8）；按钮、输入框、日期块 `rounded-md`（6）；标签 `rounded`（4）；筛选项 `rounded-full`
- 阴影：默认不用阴影，用 1px `neutral-200` 边框区分；悬停时 `hover:border-primary-300 hover:shadow-sm`。`main.css` 里旧的 `.card`、`.feature-card`（大圆角 + 大阴影）不再用于新页面
- 断点：Tailwind 默认（sm 640 / md 768 / lg 1024）。截图验收宽度 375 和 1440
  - 主导航 6 项（D1 加了补贴政策），`lg` 以下用折叠菜单
  - 顶部联系条 `md` 以上显示，手机底部联系条 `md` 以下显示（D2）
  - 网格：手机 1 列、`sm` 2 列、`lg` 3 列（案例 3×2，R4）

## 4. 按钮与标签（`main.css` 全局类）

| 类名 | 样式 | 用在 |

| `.btn .btn-primary` | 主色实底，高 40 | 立即报名、提交、查看结果；每个区域只放一个 |
| `.btn .btn-secondary` | 主色描边 | 电话咨询、咨询下一届、清空筛选 |

## 5. 通用组件（`components/common/`）

项目惯例是显式 `import` 组件。

| 组件 | 作用 | 主要参数 / 插槽 | 用在哪些页面 |
|---|---|---|---|
| `PageBanner` | 列表页标题区：面包屑 + 英文小字 + 标题 + 一句话；传 `image` 时为大图背景 + 白字 | `title` `en` `desc` `crumbs` `image`；默认插槽放右侧统计数字 | 展会 / 简讯 / 案例 / 补贴列表、关于、联系 |
| `AppBreadcrumb` | 面包屑，首项固定「首页」，末项过长截断 | `items: { name, to? }[]` | 详情页（标题区不用 PageBanner 时单独用） |
| `SectionTitle` | 区块标题 | `title` `eyebrow` `desc`；`#action` 放「查看全部」 | 首页各区块、关于我们 |
| `ListRow` | 列表行，整行可点，按钮插槽在上层可单独点 | `to` `title` `muted`；`#leading` `#badge` 默认插槽（信息行）`#actions` | 展会列表、简讯列表、补贴列表、首页展会、详情页「同类展会」 |
| `DateBlock` | 展会日期块（月.日 + 年） | `date`（YYYY-MM-DD）`muted` | 放在 `ListRow` 的 `#leading` |
| `ContentCard` | 图文卡片，封面 4:3 裁切，无图 / 加载失败显示占位底色 | `to` `title` `cover`；默认插槽放日期 | 成功案例列表、展团风采 |
| `FilterBar` | 搜索框 + 筛选项 + 已选条件（可删、可清空）；手机端筛选项收进底部抽屉 | `v-model:keyword` `tags` `placeholder`；事件 `search` `remove(key)` `clear`；默认插槽放筛选控件 | 展会列表（简讯、补贴只用搜索框，不传插槽） |
| `AppPagination` | 分页，只有一页时隐藏；手机端小尺寸、最多 5 个页码 | `v-model` 页码、`total` `pageSize` | 所有列表页 |
| `EmptyState` | 空状态，必须给至少一个出口 | `title` `desc` `icon`；默认插槽放按钮 | 列表 0 条、搜索无结果 |
| `ConsultBar` | 咨询转化条：标题 + 电话按钮 + 「联系顾问」；传 `image` 时为大图背景 | `title` `desc` `image`；默认插槽可替换第二个按钮 | 每页页脚前一条，文案见页面清单各页 |
| `ConsultantCard` | 顾问卡片：电话可拨、微信号可复制 | `consultant`（类型 `Consultant`，见 `types/contact.ts`） | 展会详情（前 2 位，D6）、关于我们、联系我们 |
| `MediaBackground` | 大图背景：照片 + 主色叠加 + 深色渐变，放在 `relative` 容器里 | `src` `eager`（首屏图） | `PageBanner`、`ConsultBar`、首页轮播内部使用 |
| `CountUp` | 数字滚动计数，只播一次 | `value` `suffix` | 首页信任数字条、关于我们（D3） |

指令 `v-reveal`（`plugins/reveal.ts`）：滚动入场，值为同组序号，用法见第 10 节。

工具函数：`telHref(phone)`（`utils/url.ts`，多个号码取第一个、去空格）；`requiredRule(label)`、`mobileRule`（`utils/validate.ts`，手机号 `1[3-9]` 开头 11 位）。

**不单独做组件、直接用现成的**
- 骨架屏：`el-skeleton`（翻页、站内跳转时放在列表区）
- 图片放大：`el-image` 的 `preview-src-list`（案例详情、照片墙）
- 弹窗、抽屉、下拉：Element Plus（`el-dialog` `el-drawer` `el-select`）
- 富文本正文渲染：由 #30 统一

## 6. 表单

- 标签在输入框上方（`label-position="top"`，`size="large"`），手机和桌面一致
- 必填项标星，失焦时校验；手机号输入框加 `inputmode="tel"` `maxlength="11"`

## 10. 动效与背景图

2026-11-24 人工确认：参考 [maifexpo](https://www.maifexpo.com/) 的切换动效和大图背景，在「专业」和「炫酷」之间偏专业。

**参考站拆解**

| 站点 | 做法 | 处理 |
|---|---|---|
| maifexpo | 区块整幅照片背景 + 深海军蓝遮罩 | 吸纳：`MediaBackground` |
| maifexpo | 轮播切换时文字依次入场（animate.css）；滚动时淡入上浮（WOW.js，每项错开 0.1s） | 吸纳并收敛：位移 16px、400ms、只播一次 |
| maifexpo | 悬停图片放大 1.1 + 旋转 3°，0.5s | 只保留放大：1.05、300ms |
| maifexpo | 内容默认隐藏，滚动到才出现 | 不吸纳：慢网速、截图和抓取时一片空白 |
| [汉诺威工业博览会](https://www.hannovermesse.de/en/) | 首屏视频 + 品牌色滤镜，带暂停按钮；首屏底部叠压快捷入口卡 | 吸纳暂停按钮；快捷入口卡留给 #3 首页 |
| [法兰克福展览](https://www.messefrankfurt.com/frankfurt/en.html) | 实拍照片上压实色文字块，文字始终清楚 | 吸纳思路：遮罩左深右浅，文字放左侧 |
| [傲邦](https://www.aobonexpo.com/) | fullPage 整屏滚动劫持 + AI 粒子城市图 | 不吸纳：劫持滚动、模板感重 |
| [鹿鸣](https://www.lumexpo.com/) | 视差滚动 | 不吸纳：视差易引起眩晕（NN/g） |

**规则**

- 只做三类动效：**入场**（滚动到视口，只播一次）、**切换**（轮播）、**悬停反馈**。不做页面切换动画、视差、滚动劫持
- 时长：悬停 / 反馈 300ms 以内；入场 400ms；轮播图片淡入 800ms、缓慢缩放 7 秒（1.06 → 1）。缓动一律 ease-out。依据：NN/g 建议多数动画 100～400ms，超过 500ms 显得拖沓（[NN/g 动画时长](https://www.nngroup.com/articles/animation-duration/)）
- 幅度：位移不超过 24px（入场用 16px），放大不超过 1.06；不旋转、不弹跳、不闪烁；同一屏只有一处在自动动
- 自动播放超过 5 秒的内容（轮播、视频）必须有暂停按钮（[WCAG 2.2.2](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide)）
- 系统开了「减少动态效果」（`prefers-reduced-motion`）：轮播不自动播放，所有过渡立即完成（`main.css` 末尾）
- 首屏内容不做入场动画，服务端渲染的内容直接可见；只有首屏以下的元素滚动到时才播放（`utils/motion.ts` 的 `belowFold`）

**用法**

```vue
<!-- 同一组卡片按序号错开 80ms，最多错开 5 项 -->
<ContentCard v-for="(c, i) in list" :key="c.id" v-reveal="i" … />
<PageBanner title="成功案例" en="Cases" :image="bannerImage" />
<ConsultBar title="想参加同类展会？" :image="bannerImage" />
<CountUp :value="countries" suffix="+" />
```

**背景大图**

- 用在：首页轮播、列表页标题区（`PageBanner`）、咨询条（`ConsultBar`）。每页最多 1～2 处，其余区块保持白底 / 浅灰底
- 一律通过 `MediaBackground` 叠遮罩（主色 `primary-800/40` 正片叠底 + 左深右浅的深色渐变），文字放左侧，保证白字清楚
- 首屏大图加 `eager`（立即加载 + `fetchpriority="high"`），不要懒加载（[web.dev LCP](https://web.dev/articles/optimize-lcp)）；其余懒加载
- 尺寸：宽 1600～1920，JPEG / WebP，单张控制在 250KB 以内
- 素材优先级：公司真实出团、展会现场照片 > 正版图库 > AI 合成图。原型占位图来自 Wikimedia（CC0）和 Pexels，出处见 `mock/public/mock/CREDITS.md`；上线前换成真实照片（#23）
- 首屏用大图轮播，不用视频（人工确认）：轮播图后台可维护（R2），体积小、加载快
