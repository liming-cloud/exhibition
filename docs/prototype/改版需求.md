# 官网改版需求（原型第 2 轮）

来源：客户 2026-11-24 对现网的 7 条标注反馈。本文先定义需求，再给出调研结论和设计方案；原型按本文实现，确认后接真实接口上线。

## 0. 怎么看原型

**在线预览（推荐）**：https://liming-cloud.github.io/exhibition/ ，各页面桌面/手机截图：https://liming-cloud.github.io/exhibition/screenshots/ 。master 每次更新后自动重新发布（约 3 分钟）。

**本机运行**：

```bash
cd exhibition-webside
nvm use                              # 需要 Node 22（见 .nvmrc）
NUXT_PUBLIC_MOCK=1 pnpm dev          # 不需要后端，/api 返回 mock/data.ts 的模拟数据
# http://localhost:3000/
```

## 1. 需求清单

| # | 客户反馈 | 需求定义 | 验收标准 |
|---|---|---|---|
| R1 | Logo 不对，得改 | 页头、页脚使用公司正式 Logo 图片，替换现在的「YB」色块 + 文字 | 正式 Logo 放进 `exhibition-webside/public/`，改 `constants/site.ts` 的 `logo` 路径即生效 |
| R2 | 可以多图轮转，客户自己更新上传 | 首页 Banner 轮播所有「启用」的轮播图，按后台排序；客户在后台「轮播图」上传、排序、停用 | 后台新增/停用一张图，刷新首页即生效；标题文字在任何图片上都清晰可读；有链接时显示「了解更多」 |
| R3 | 我们的服务：放页面底部，缩小占比 | 首页服务区移到最后（页脚之前），改为一行紧凑展示 6 项 | 桌面端服务区高度不超过一屏的 1/3；手机端 2 列 |
| R4 | 成功案例：不在首页展示，只在内页；内页一次展示 6 个 | 首页移除成功案例区；案例列表页每页 6 个 | 首页无案例区；`/cases` 每页 6 条（桌面 3×2），可翻页 |
| R5 | 全球展会分布下面加一个板块，直接展示展会列表，客户进来就能看到我们做哪些国家的项目 | 地图下方新增「展会项目」板块：按大洲列出我们有展会的国家及数量，下面列出展会（即将开始的在前）；点国家或地图上的点即筛选 | 打开首页不用点击就能看到全部国家和近期展会；点「德国」列表只剩德国展会；「查看全部」跳到展会列表页并带上国家筛选 |
| R6 | 行业动态 → 市场简讯 | 导航、页脚、列表页标题、详情页面包屑统一改名「市场简讯」，地址 `/news` 不变 | 全站搜不到「行业动态」 |
| R7 | 关注我们：直接放我的二维码 | 页脚「关注我们」改为直接显示微信二维码图片（不再是图标按钮） | 二维码图片放进 `public/`，改 `constants/site.ts` 的 `qrcode` 路径即生效 |

保持不变的功能：展会列表筛选（关键词/行业/年份/大洲/国家）与分页、展会详情与在线报名、市场简讯与案例的列表/详情、补贴政策、关于我们、联系我们、SEO（每页标题、sitemap）。

## 2. 调研结论

调研了 10 家同类出国展会组展公司官网和 4 个海外展会目录站：

| 站点 | 可借鉴 |
|---|---|
| [盈拓 intopexpo.com](https://www.intopexpo.com/zh-cn/) | 页头放全国热线；用数字（展会数、国家数）建立信任 |
| [优合 uexpo.com.cn](http://www.uexpo.com.cn/) | 和我们同是能源行业；「日期在前」的展会行列表，扫一眼就知道时间 |
| [麦瑞 maryexpo.com](https://www.maryexpo.com/) | 「近期展会」卡片只放时间 + 地点两行，信息密度合适 |
| [汇和 zhanc.com](https://zhanc.com/index.html) | 服务只列 4 项一行，靠后放；底部「现在致电」 |
| [中盛 ws-expo.com](https://zs.ws-expo.com/) | 联系方式写「微信同号」，降低加微信门槛 |
| [鹿鸣 lumexpo.com](https://www.lumexpo.com/) | 「出团风采」用展团合影建立信任——和我们的横幅素材一致 |
| [迈风 maifexpo.com](https://www.maifexpo.com/) | 商务蓝、中英双行导航、大洲 tab 展会目录 |
| [FinderExpo](https://finderexpo.com/)、[hostess-world](https://www.hostess-world.com/events?lng=en) | 按国家浏览：国家名 + 展会数量，点进去看该国全部展会 |
| [MesseIndex](https://www.messeindex.de/en/trade-fair-calendar) | 按月份时间顺序排列，「即将开始」优先 |

结论：
1. 访客最关心「去哪个国家、什么时候、什么行业」，展会信息要**日期在前、国家醒目**，并直接在首页露出（对应 R5）。
2. 服务项目是同质化内容，同行都放得靠后、做得紧凑（对应 R3）。
3. 横幅类展团合影是最有说服力的素材，Banner 要大图通栏、文字压在渐变遮罩上（对应 R2）。
4. 电话、微信二维码在页头和页脚都要一眼能找到。

## 3. 设计方案

**整体风格**：商务、克制、信息清楚。去掉现网的大号渐变标题和强阴影；白底 + 浅灰分区，1px 细边框、8px 圆角；标题左侧配英文小字（如 `GLOBAL NETWORK`）。

**配色**：2026-11-26 定为**橙色**（#23），蓝色方案已删除。

**字体与性能**：去掉 Google Fonts 和 cdnjs 的外链（国内访问慢或不可用，会拖慢首屏），使用系统中文字体；图标继续用本地的 Font Awesome。

**页面结构**

```
页头：[顶部条] 服务热线 010-53630591/2/3 · 手机/微信 18310336602
      [主导航] Logo | 首页  展会列表  市场简讯  成功案例  关于我们 | [联系我们]
首页：
  1 Banner 通栏轮播（R2）
  2 全球展会分布：世界地图，点国家 → 筛选下方列表
  3 展会项目（R5）：大洲分组的国家标签（含数量）+ 日期在前的展会列表 + 查看全部
  4 我们的服务（R3）：6 项一行，紧凑
页脚：关于我们 | 快速链接 | 联系我们 | 关注我们（微信二维码，R7）
```

内页本轮只改需求涉及的部分（案例每页 6 个、市场简讯改名），其余内页沿用现有页面，统一换上新页头页脚；首页确认后再按同一风格改内页。
