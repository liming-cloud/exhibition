# 官网页面清单（整站设计 ①）

对应 Issue #18。逐页定下「放哪些模块、按什么顺序、数据从哪来」，作为 #19 设计规范和 #3 #20 #21 #22 页面开发的依据。

- 需求来源：`docs/prototype/改版需求.md`（客户反馈 R1～R7、第 2 节调研结论）
- 现状来源：`exhibition-webside/pages/`、`components/`、`mock/api.ts`（2026-11-24 master `f105867`）
- 调研时间：2026-11-24，链接均为当日可访问页面

**数据来源标记**

| 标记 | 含义 |
|---|---|
| 【接口】 | 现有后端接口，字段见 `exhibition-webside/types/` |
| 【#5】 | 新增约定，mock 已有，后端由 Issue #5 实现（`/exhibition/featured`、`/contact/consultants`、展会 `featured/coverUrl/summary`） |
| 【计算】 | 前端从接口数据算出，不新增接口 |
| 【写死】 | 前端常量（`constants/site.ts` 或页面内），改动需发版 |
| 【待定】 | 原为待拍板项，已全部确认，结论见文末「已确认决定」 |

**所有页面通用的状态要求**（下文各页只写差异）

- 加载：列表/详情走 SSR 直出，首屏无加载态；站内跳转和翻页时列表区显示骨架屏，不整页白屏
- 空数据：列表区显示「暂无 xx」+ 一个出口（查看全部 / 联系顾问），不留空白
- 长标题：卡片标题最多 2 行省略，详情页标题完整显示并允许换行；展会中英文名混排不撑破卡片
- 手机端：375 宽无横向溢出（截图脚本会告警）；卡片单列；筛选项折叠成一行横向滚动或抽屉
- 每页独立 `title`/`description`（`useSeoMeta`），详情页取内容标题

**状态**：电话有多个时顶部条只放前 2 个，其余进联系页；Logo 图片未到位时用文字占位（现状）。

## 1. 首页 `/`

**目的**：让访客 10 秒内知道「我们做哪些国家、什么时候、什么行业的展会」，并能直接点进展会或联系顾问。
**主要动作**：看近期展会 → 点国家筛选 → 进详情报名；或直接打电话。

**参照**
- [优合 uexpo](http://www.uexpo.com.cn/)：「优势项目」用 `2026.05.12-14 + 展会名` 的行列表，日期在前，扫一眼就知道时间；同为能源行业
- [迈风 maifexpo](https://www.maifexpo.com/)：展会目录按大洲 tab（欧洲、亚洲、中东、非洲…）切换
- [汇和 zhanc](https://zhanc.com/index.html)：服务只列 4 项、靠后放；每屏底部「现在致电 400-…」
- [盈拓 intopexpo](https://www.intopexpo.com/zh-cn/)：用「615 展会 / 50 国家 / 187 城市」数字建立信任

**模块（自上而下）**

| # | 模块 | 内容 | 数据来源 |
|---|---|---|---|
| 1 | Banner 通栏轮播（R2） | 所有启用的轮播图按 sort 播放；标题压在渐变遮罩上；有 link 时显示「了解更多」 | 【接口】`/carousel/page`（status=0） |
| 2 | 信任数字条（D3） | 合作国家数、在售展会数 + 成立年份等 3～4 个数字 | 国家/展会数【计算】；其余【写死】，需人提供 |
| 3 | 全球展会分布 | 世界地图，有展会的国家打点；点国家 → 筛选模块 4 | 【接口】`/exhibition/area` + `/exhibition/page` |
| 4 | 展会项目（R5） | 大洲分组的国家标签（含数量）；日期在前的展会行列表（即将开始在前，已结束排后并置灰），主推展会带「主推」标记；首页放 6 个，底部「查看更多展会」按钮 → `/exhibitions?country=` | 【接口】展会列表 +【#5】`featured`；分组/排序【计算】 |
| 5 | 我们的服务（R3） | 6 项一行，图标 + 2～4 字标题 + 一句话；手机端 2 列；高度 ≤ 1/3 屏 | 【写死】 |
| 6 | 咨询条 | 「不知道选哪个展？」+ 电话 +「联系顾问」按钮 | 【接口】phone |

**不放**：成功案例（R4）；出团风采是否上首页见 D4。

**状态**：轮播图 0 张时显示纯色底 + 公司名标语；某国家无即将开始的展会时只显示已结束的并置灰；展会列表首页最多显示 6 个，其余走「查看更多展会」；地图在手机端缩为国家标签（地图本身不交互）。

## 2. 展会列表 `/exhibitions`

**目的**：按国家/行业/时间找到要去的展会。
**主要动作**：筛选 → 点进详情；或在列表直接「报名」。

**参照**
- [长城展览 chgie](https://www.chgie.com/showcenter/index_1--14.htm)：每条展会 = 中文名 + 英文名 + 两行简介 + 「地点 / 周期 / 时间」一行 + 「查看联系方式」「在线申请」两个按钮
- [视展 shizhanexpo](https://www.shizhanexpo.com/)：表格首列是「开始时间」，按时间排
- [贸有 wesexpo](https://www.wesexpo.com/zh-cn)：每个展会显示距报名截止天数（「112 Last Day」），制造紧迫感
- [MesseIndex](https://www.messeindex.de/en/trade-fair-calendar)：按月份时间顺序，「即将开始」优先

**模块**

| # | 模块 | 内容 | 数据来源 |
|---|---|---|---|
| 1 | 页面标题区 | 「展会列表」+ 英文小字 + 一句话（共 N 个展会，覆盖 M 个国家） | 【计算】 |
| 2 | 筛选条 | 关键词、行业、年份、大洲 → 国家（联动）；已选条件显示为可删除的标签 + 「清空」；筛选条件写进 URL（可分享、首页 `?country=` 跳转可用） | 【接口】`/exhibition/area`；行业【写死】`ExhibitionTypeMap` |
| 3 | 展会列表 | 每行：日期块（月/日，年份小字）\| 展会名（2 行省略）+ 国家·城市/场馆 + 行业标签 + 主推标记 \| 「详情」「报名」；已结束的置灰、不显示报名 | 【接口】`/exhibition/page` +【#5】`featured` |
| 4 | 分页 | 每页 10 条，显示总数 | 【接口】total |
| 5 | 咨询条 | 「没找到想去的展会？顾问帮你找」+ 电话 | 【接口】phone |

**状态**：筛选后 0 条 → 「没有符合条件的展会」+「清空筛选」+「联系顾问」；手机端筛选收进「筛选」抽屉，列表上方保留已选标签；报名弹窗见第 3 节。

**现状差异**：现在是卡片网格、前端全量拉取后分页（`pageSize: 999`），展会数到几百条前可接受，不在本轮改。

## 3. 展会详情 + 报名 `/exhibitions/:id`

**目的**：让访客判断「这个展值不值得去」，并当场留下联系方式。
**主要动作**：看时间地点和简介 → 报名（或打电话）。

**参照**
- [长城展览 chgie 详情](https://www.chgie.com/exhireg-102.htm)：固定小节「展会简介 / 上届数据 / 展出内容 / 费用标准 / 我司服务 / 报名步骤（含截止时间）/ 联系人」，信息全且顺序稳定
- [展昭 chanchao](https://www.chanchao.com.tw/mechanical/)：页首一张「主办单位 / 展出时间 / 展出地点」信息表；「展示费用」单独成表
- [万盛 ws-expo](https://fair.ws-expo.com/)：展会卡片写「¥22,000 起组团参展」「核心展位优先预订」，价格和稀缺性前置

**模块**

| # | 模块 | 内容 | 数据来源 |
|---|---|---|---|
| 1 | 面包屑 | 首页 / 展会列表 / 展会名 | — |
| 2 | 头图 + 标题区 | 封面图（无图用主题色块）；展会名（完整显示）；一句话简介；行业标签、主推标记 | 【接口】name、exhibitionType；【#5】coverUrl、summary、featured |
| 3 | 关键信息卡 | 时间、国家、城市/场馆、行业 4 项；主按钮「立即报名」+ 次按钮「电话咨询」；桌面端在右侧随滚动吸附，手机端底部固定报名按钮 | 【接口】time、countryName、location |
| 4 | 正文 | 后台富文本；建议运营按「展会简介 / 展品范围 / 参展费用 / 报名流程」写小标题（D5） | 【接口】content |
| 5 | 负责顾问 | 顾问卡片：姓名、负责区域、电话、微信 | 【#5】`/contact/consultants`（按 sort 取前 2 个，或按区域匹配，见 D6） |
| 6 | 同国家/同行业展会 | 最多 4 条，日期在前 | 【计算】从展会列表筛 |
| 7 | 报名弹窗 | 展会名回显；公司/个人名称、联系人、手机号（校验 1[3-9] 开头 11 位）；提交中按钮禁用防重复；成功后提示「顾问将在 1 个工作日内联系您」并显示电话 | 【接口】`/exhibition/registration/submit`；字段是否增加见 D7 |

**状态**：id 不存在 → 404；展会已结束 → 报名按钮换成「咨询下一届」（打开同一报名表，便于顾问跟进）；正文为空 → 隐藏正文区，关键信息卡和顾问照常显示；提交失败 → 表单保留已填内容并提示重试。

## 8. 补贴政策列表 `/subsidies`

**目的**：降低客户「出国参展太贵」的顾虑——补贴是促成报名的卖点。
**主要动作**：找到自己所在地的政策 → 咨询能否申报。

**参照**
- [砺展 expodmc 补贴政策](https://www.expodmc.com/subsidy/)：按省份/城市索引 + 「资质审核流程」「拨付申请材料清单」两篇通用指南置顶
- [万盛 ws-expo](https://fair.ws-expo.com/)：首页数字「70% 最高补贴比例」，把补贴当卖点
- [天津市商务局 2025 申报指南](https://exhibition.ccpit.org/cms/article/file/showFile?path=Article%2F2025%2F06%2F10%2F11-34-3547545.pdf)：政策原文按「支持内容 / 比例与限额 / 申报时间 / 所需材料」组织——公司在天津，这是最贴近客户的一类内容

**模块**

| # | 模块 | 内容 | 数据来源 |
|---|---|---|---|
| 1 | 页面标题区 | 「补贴政策」+ 一句话（「参展费用最高可获 50%～70% 补贴，顾问免费帮您评估」，比例措辞需人确认） | 【写死】 |
| 2 | 搜索框 | 按标题搜索 | 【接口】`/subsidies/page?title=` |
| 3 | 政策列表 | 每条：标题（2 行）+ 有效期 + 状态标签（申报中 / 未开始 / 已截止）+ 补贴金额（`price > 0` 才显示） | 【接口】title、startTime、endTime、price；状态【计算】 |
| 4 | 分页 | 每页 12 条 | 【接口】 |
| 5 | 咨询条 | 「不确定能不能申报？」+ 电话 + 顾问 | 【接口】phone |

**状态**：已截止的排后并置灰；无数据 → 「政策整理中」+ 电话；按地区筛选见 D10。

## 12. 404 / 错误页（`error.vue`，现在没有）

**目的**：链接失效（尤其展会下架后搜索引擎里的旧链接）时把访客留住。

**参照**
- [NN/g: Improving the Dreaded 404 Error Message](https://www.nngroup.com/articles/improving-dreaded-404-error-message/)：说清找不到、不怪用户、给出下一步（链接或搜索）
- [NN/g: Error-Message Guidelines](https://www.nngroup.com/articles/error-message-guidelines/)：用普通话不用错误码；提供能直接点的补救选项
- 同类官网 404 多为服务器默认页，没有可借鉴的，按上面两条做

**模块**

| # | 模块 | 内容 | 数据来源 |
|---|---|---|---|
| 1 | 说明 | 「页面不存在或展会已下架」；500 时为「页面暂时打不开，请稍后再试」 | 【写死】，按 `statusCode` 区分 |
| 2 | 出口 | 「返回首页」「查看全部展会」两个按钮 | — |
| 3 | 近期展会 | 3 条即将开始的展会 | 【接口】展会列表（接口失败则隐藏） |
| 4 | 联系方式 | 电话 | 【写死】兜底（错误页不依赖接口） |

**状态**：沿用全局页头页脚；HTTP 状态码保持 404（不要 200，避免被搜索引擎收录）。
