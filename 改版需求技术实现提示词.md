## 项目概述

### 项目技术栈说明
- **前端官网**: `exhibition-webside` - Nuxt 3 + Vue 3 + TypeScript + TailwindCSS + Element Plus
- **管理后台**: `exhibition-admin` - Vue 3 + Vite + TypeScript + Element Plus + Pinia
- **后端API**: `admin` - Spring Boot 3 + MyBatis Plus + MySQL + Java 17 + Hutool
- **设计系统**: 主色调橙色（#ff5a1f），强调色青色（#14b8a6），简洁商务风格

## 3. 展会报名功能实现

### 3.1 数据库创建报名表
**文件**: `admin/src/main/resources/db/migration/create_exhibition_registration.sql`

**需求**: 创建报名表，包含展会id、公司或个人名称、联系人姓名、联系电话等字段

**实现代码**:
```sql
CREATE TABLE exhibition_registration (
  id INT PRIMARY KEY AUTO_INCREMENT COMMENT '报名ID',
  exhibition_id INT NOT NULL COMMENT '展会ID',
  company_or_personal_name VARCHAR(200) NOT NULL COMMENT '公司或个人名称',
  contact_name VARCHAR(100) NOT NULL COMMENT '联系人姓名',
  contact_phone VARCHAR(20) NOT NULL COMMENT '联系电话',
  contact_progress ENUM('未联系', '已联系', '跟进中', '已确认') DEFAULT '未联系' COMMENT '联系进度',
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '报名时间',
  update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  INDEX idx_exhibition_id (exhibition_id),
  INDEX idx_contact_phone (contact_phone),
  INDEX idx_create_time (create_time)
) COMMENT='展会报名表';
```

### 3.3 报名接口控制器
**文件**: `admin/src/main/java/cn/exhibition/admin/controller/ExhibitionRegistrationController.java`

**实现代码**:
```java
package cn.exhibition.admin.controller;

import cn.exhibition.admin.database.PageQuery;
import cn.exhibition.admin.database.TableDataInfo;
import cn.exhibition.admin.domain.R;
import cn.exhibition.admin.domain.entity.ExhibitionRegistrationPo;
import cn.exhibition.admin.service.ExhibitionRegistrationService;
import com.baomidou.mybatisplus.core.metadata.IPage;
import lombok.RequiredArgsConstructor;
import org.springframework.web.bind.annotation.*;

/**
 * 展会报名控制器
 */
@RestController
@RequestMapping("/exhibition/registration")
@RequiredArgsConstructor
public class ExhibitionRegistrationController {

    private final ExhibitionRegistrationService registrationService;

    /**
     * 提交报名
     */
    @PostMapping("/submit")
    public R<Void> submitRegistration(@RequestBody ExhibitionRegistrationPo registration) {
        registrationService.save(registration);
        return R.ok("报名成功");
    }

    /**
     * 分页查询报名列表
     */
    @GetMapping("/page")
    public TableDataInfo<ExhibitionRegistrationPo> pageList(PageQuery pageQuery) {
        IPage<ExhibitionRegistrationPo> page = registrationService.pageWithExhibitionInfo(pageQuery);
        return TableDataInfo.build(page);
    }

    /**
     * 更新联系进度
     */
    @PutMapping("/update-progress/{id}")
    public R<Void> updateProgress(@PathVariable Integer id, @RequestParam String progress) {
        registrationService.updateProgress(id, progress);
        return R.ok("更新成功");
    }

    /**
     * 获取报名详情
     */
    @GetMapping("/detail/{id}")
    public R<ExhibitionRegistrationPo> getDetail(@PathVariable Integer id) {
        return R.ok(registrationService.getById(id));
    }

    /**
     * 删除报名记录
     */
    @DeleteMapping("/delete/{id}")
    public R<Void> delete(@PathVariable Integer id) {
        registrationService.removeById(id);
        return R.ok("删除成功");
    }
}
```

```vue
<template>

        <p><i class="fas fa-tag mr-2 text-primary-500"></i>{{ exhibition?.exhibitionType }}</p>
      </div>
    </div>

    <!-- 报名表单 -->
    <el-form ref="formRef" :model="form" :rules="rules" label-width="120px">
      <el-form-item label="公司/个人名称" prop="companyOrPersonalName">
        <el-input v-model="form.companyOrPersonalName" placeholder="请输入公司或个人名称" />
      </el-form-item>
      
      <el-form-item label="联系人姓名" prop="contactName">
        <el-input v-model="form.contactName" placeholder="请输入联系人姓名" />
      </el-form-item>
      
      <el-form-item label="联系电话" prop="contactPhone">
        <el-input v-model="form.contactPhone" placeholder="请输入联系电话" />
      </el-form-item>
    </el-form>

    <template #footer>
      <div class="dialog-footer">
        <el-button @click="handleClose">取消</el-button>
        <el-button type="primary" @click="handleSubmit" :loading="loading"
                   class="!bg-primary-500 !border-primary-500 hover:!bg-primary-600">
          提交报名
        </el-button>
      </div>
    </template>
  </el-dialog>
</template>

<script setup lang="ts">
import type { Exhibition } from '~/types/exhibition'
import type { FormInstance, FormRules } from 'element-plus'

interface Props {
  modelValue: boolean
  exhibition: Exhibition | null
}

interface Emits {
  (e: 'update:modelValue', value: boolean): void
  (e: 'submit', data: any): void
}

const props = defineProps<Props>()
const emit = defineEmits<Emits>()

const visible = computed({
  get: () => props.modelValue,
  set: (value) => emit('update:modelValue', value)
})

const formRef = ref<FormInstance>()
const loading = ref(false)

// 表单数据
const form = reactive({
  exhibitionId: 0,
  companyOrPersonalName: '',
  contactName: '',
  contactPhone: ''
})

// 表单验证规则
const rules: FormRules = {
  companyOrPersonalName: [
    { required: true, message: '请输入公司或个人名称', trigger: 'blur' }
  ],
  contactName: [
    { required: true, message: '请输入联系人姓名', trigger: 'blur' }
  ],
  contactPhone: [
    { required: true, message: '请输入联系电话', trigger: 'blur' },
    { pattern: /^1[3-9]\d{9}$/, message: '请输入正确的手机号码', trigger: 'blur' }
  ]
}

// 监听展会信息变化
watch(() => props.exhibition, (newExhibition) => {
  if (newExhibition) {
    form.exhibitionId = newExhibition.id!
  }
}, { immediate: true })

// 提交表单
const handleSubmit = async () => {
  if (!formRef.value) return
  
  try {
    await formRef.value.validate()
    loading.value = true
    emit('submit', { ...form })
  } catch (error) {
    console.error('表单验证失败:', error)
  } finally {
    loading.value = false
  }
}

// 关闭弹窗
const handleClose = () => {
  // 重置表单
  if (formRef.value) {
    formRef.value.resetFields()
  }
  Object.assign(form, {
    exhibitionId: 0,
    companyOrPersonalName: '',
    contactName: '',
    contactPhone: ''
  })
  emit('update:modelValue', false)
}
</script>
```

```vue
        </el-form-item>
        
        <el-form-item label="工作时间" prop="workingHours">
          <el-input v-model="form.workingHours" placeholder="请输入工作时间" />
        </el-form-item>
        
        <el-form-item>
          <el-button type="primary" @click="handleSave" :loading="loading">
            保存设置
          </el-button>
          <el-button @click="handleReset">重置</el-button>
        </el-form-item>
      </el-form>
    </el-card>
  </div>
</template>

<script setup lang="ts">
import { ref, reactive, onMounted } from 'vue'
import { ElMessage } from 'element-plus'
import type { FormInstance, FormRules } from 'element-plus'
import { getContactInfo, updateContactInfo } from '@/api/contact'

const formRef = ref<FormInstance>()
const loading = ref(false)

// 表单数据
const form = reactive({
  id: 0,
  companyAddress: '',
  contactPhone: '',
  contactPerson: '',
  companyEmail: '',
  workingHours: ''
})

// 表单验证规则
const rules: FormRules = {
  companyAddress: [
    { required: true, message: '请输入公司地址', trigger: 'blur' }
  ],
  contactPhone: [
    { required: true, message: '请输入联系电话', trigger: 'blur' }
  ],
  contactPerson: [
    { required: true, message: '请输入联系人姓名', trigger: 'blur' }
  ],
  companyEmail: [
    { type: 'email', message: '请输入正确的邮箱地址', trigger: 'blur' }
  ]
}

// 获取联系信息
const fetchContactInfo = async () => {
  try {
    const response = await getContactInfo()
    if (response.data) {
      Object.assign(form, response.data)
    }
  } catch (error) {
    console.error('获取联系信息失败:', error)
  }
}

// 保存设置
const handleSave = async () => {
  if (!formRef.value) return
  
  try {
    await formRef.value.validate()
    loading.value = true
    await updateContactInfo(form)
    ElMessage.success('保存成功')
  } catch (error) {
    if (error !== false) { // 非表单验证错误
      ElMessage.error('保存失败')
    }
  } finally {
    loading.value = false
  }
}

// 重置表单
const handleReset = () => {
  if (formRef.value) {
    formRef.value.resetFields()
  }
  fetchContactInfo()
}

onMounted(() => {
  fetchContactInfo()
})
</script>

  max-width: 42rem;
```

## 7. 技术实现规范总结

### 7.1 代码规范
- **TypeScript**: 使用严格模式，所有组件使用 Composition API
- **ESLint + Prettier**: 遵循现有配置，统一代码风格
- **命名规范**: 组件使用 PascalCase，变量使用 camelCase，常量使用 SCREAMING_SNAKE_CASE

### 7.2 组件规范
- **Props定义**: 使用 TypeScript 接口定义 props 类型
- **事件命名**: 使用 kebab-case，如 `@update:model-value`
- **组件导入**: 使用相对路径导入组件，使用 `~/` 别名导入工具函数

### 7.3 样式规范
- **TailwindCSS**: 基于现有设计系统，主色调橙色系（#ff5a1f）
- **响应式**: 使用 `sm:` `md:` `lg:` 断点进行响应式设计
- **间距**: 使用 Tailwind 标准间距，减小组件间距使用 `py-8` 替代 `py-12`

### 7.4 接口规范
- **RESTful API**: 统一使用 REST 风格接口设计
- **返回格式**: 统一使用 `R<T>` 和 `TableDataInfo<T>` 返回格式
- **错误处理**: 统一异常处理，返回友好的错误信息

### 7.5 数据库规范
- **字段命名**: 使用下划线命名法，如 `exhibition_type`
- **索引**: 为常用查询字段添加索引
- **注释**: 所有表和字段都添加中文注释

### 7.6 性能优化
- **SSR**: 使用 Nuxt SSR 进行服务端渲染
- **图片优化**: 使用 WebP 格式，添加懒加载
- **组件懒加载**: 使用 `defineAsyncComponent` 进行组件懒加载
- **缓存策略**: 合理使用浏览器缓存和 CDN

### 7.7 安全规范
- **输入验证**: 前后端双重验证用户输入
- **XSS防护**: 使用 `v-html` 时确保内容安全
- **CSRF防护**: 添加 CSRF Token 验证
